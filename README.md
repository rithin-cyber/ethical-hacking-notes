## How I Approach Testing

1. Identify the target and confirm the authorized testing scope.
2. Enumerate relevant services, endpoints, and application behavior.
3. Develop a test hypothesis and validate it safely.
4. Capture evidence and distinguish confirmed findings from assumptions.
5. Document impact, severity rationale, and remediation.
6. Retest when appropriate.
